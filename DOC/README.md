# Описание 
**Base Test Platform** — учебно-демонстрационная платформа для изучения практик тестирования на реальном приложении. В основе лежит эталонное приложение **RealWorld Conduit** (блог-платформа), расширенное полным стеком инфраструктуры: CI/CD, контрактное тестирование, E2E, API-тесты.

<details>
<summary>Что есть в платформе</summary>
Проект демонстрирует:
- построение многоуровневого тест-стека (unit → integration → API → contract → E2E);
- Self-hosted CI/CD на базе **Gitea Actions**;
- контрактное тестирование с **Pact** (consumer + provider);
- современный backend на **FastAPI + asyncpg + PostgreSQL**;
- React-фронтенд из экосистемы RealWorld. Реализован через докерконтейнеры
</details>

<details>
<summary>Чего нет в платформе</summary>
упрощена безопасность до минимального порога - все сервисы взаимодействуют без авторизации или по минимально возможному порогу. Сервисы  монорепозитории
оркестрации - все в одном, без брокеров очередей
</details>

# Технические требования

- **Docker** и **Docker Compose v2** (`docker compose`).
- **Bash**: Linux, macOS или **WSL2** (на Windows команды из README для shell-скриптов предполагают запуск из WSL при пути вида `/mnt/c/...`).
- Свободные порты: **3000**, **3001**, **2222**, **9292**, **5432** (или задайте другие в `.env`).
- RAM: от ~8 ГБ.

# Быстрый запуск

Установить докер и WSL 

Клонировать репозиторий. Все установочные скрипты выполнять из корневой  директории. 



создает окружение
установить докер, все остальное можно делать в контейнерах. 
```bash
cp .env.example .env
```


```bash
chmod +x scripts/*.sh   # first time only
./scripts/01-start-infrastructure.sh
```
Скрипт: создаёт сеть `conduit-network`, поднимает **db → pact-broker → gitea**, собирает и запускает **app**, ждёт готовности health-check’ов.

```bash
./scripts/02-setup-gitea.sh
```

Проверяет пользователя администратора (при отсутствии создаёт через CLI в контейнере), выпускает API-токен (`.gitea-token`), создаёт **`conduit/monorepo`**, получает токен регистрации runner’а, при необходимости обновляет `.env`, **пересобирает и перезапускает act-runner**.

```bash
./scripts/03-push-code.sh
```
