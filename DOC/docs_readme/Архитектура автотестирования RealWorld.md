
## Уровни тестирования

| Статические тесты               | - Проверки кода на PEP 8 правила и типо-безопасноть<br>- | Контроль ошибок Тгбд Poiner и т.д.                                                                                                                                             |
| ------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Unit тесты/ Модульные тесты** | - Проверки функций с покрытием не менее 95%. <br>-       | pytest, jest<br><br>                                                                                                                                                           |
| **Контрактные тесты**           | Дизайн инструмента сконфигурирован для quality gate      | Standalone Pact<br>pact-python<br><br>│  Consumer: Jest + @pact-foundation/pact (tests/pact/consumer/)  │<br>│  Provider: pact-python verifier (tests/pact/provider/) <br>     |
| **Интеграционные тесты**        |                                                          | pytest<br><br>(pytest, backend/tests/)             │<br>│  FakeAsyncPGPool → реальная БД в транзакции (rollback)          │<br>│  AsyncClient (httpx) против ASGI-app без HTTP |
| **E2E тесты**                   |                                                          | playwright                                                                                                                                                                     |


# Таксономия тестов

Все тесты, кроме юнитов ориентированы на smoke тестирование. Это сценарии регистраци, авторизации, создания статьи. В случае с юнит-тестами, на них повешен.  

**Покрытые маршруты в pytest**
`test_authentication`, `test_login`, `test_registration`, `test_users`, `test_articles`, `test_comments`, `test_profiles`, `test_tags`, `test_error`, `test_422_error`.


# Карта каталогов

| Каталог              | Содержимое                                                                                                                                                       |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `backend/app/models` | **Нет файлов `test_*.py`.** Здесь доменные и схемные модели (Pydantic). Поведение, связанное с моделями, проверяется в `backend/tests/test_schemas` и через API. |
| `backend/tests`      | Основной набор **pytest**: API, ошибки, JWT, SQL-хелперы, формат дат.                                                                                            |
| `backend/scripts`    | Оболочечные скрипты запуска pytest с покрытием.                                                                                                                  |
| `backend/postman`    | Коллекция Newman для **чёрного ящика** против живого API.                                                                                                        |
| `tests/api`          | Отдельные **интеграционные** pytest-тесты через `requests` к поднятому стеку (по умолчанию через прокси фронта).                                                 |
| `tests/e2e`          | **E2E smoke** на Playwright (браузер + UI).                                                                                                                      |
| `tests/pact`         | **Consumer-driven contracts**: Jest + Pact (потребитель), Python verifier (провайдер).                                                                           |
